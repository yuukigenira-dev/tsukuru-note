# つくるノート

音楽・デザイン・コーディングを調べて学べる、個人用の静的Webアプリです（旧名 Creative Atlas / ATLAS）。

## 使い方
- `index.html` をブラウザで開くか、任意の静的サーバーで配信します。
  例: `python3 -m http.server 8000` → http://localhost:8000/
- ビルド不要。すべて相対パスなので GitHub Pages のサブパス（`https://<user>.github.io/<repo>/`）でも動きます。

## GitHub Pages で公開
1. このフォルダの中身をリポジトリのルートに置いて push。
2. Settings → Pages → Source: 「Deploy from a branch」、Branch: `main` / `/ (root)`。
3. 数分後に `https://<user>.github.io/<repo>/` で表示されます。

## メモ
- 保存データはブラウザの localStorage（内部キー名は旧名のまま。過去データを引き継ぐため）。
- 読みやすさの調整は最後に読み込む `tsukuru-readability.css` に集約しています。
- アイコンは `assets/brand/`（ファイル名は互換のため旧名のまま）と `favicon.ico`。
- 音源・フォントのクレジットは `AUDIO-CREDITS.txt` / `FONT-CREDITS.txt`。

## 2026-10 UI再設計（tsukuru-shell）
- `tsukuru-shell.js` / `tokens.css` を最後に読み込み、上部検索・下部タブ（調べる/学ぶ/保存/設定）・領域切替（コード/デザイン/音楽）を提供。旧ナビはDOMを残して非表示。
- テーマ: 設定 › テーマ（ライト/ダーク/端末に合わせる）。キー `atlas-appearance-v1`（値 white/dark/system）。`appearance.js` が head で適用（ちらつきなし）。
- 最後に使った領域: `tsukuru-domain-v1`（新規）。既存の localStorage キーは変更なし。
- 作曲スタジオ（進行メモ）は 設定 › 非表示の道具 から開けます。

## カテゴリの追加方法（ハンバーガーメニュー）
`tsukuru-shell.js` 冒頭の `CATEGORIES` 配列に1件追加するだけで、メニュー・調べる・学ぶに反映されます。
```js
{id:"newcat", label:"新カテゴリ", icon:"★", order:4,
 quick:["toolA","toolB"], learn:["lessonA"], question:"freequestion-newcat", other:[]}
```
- `id` は既存画面の領域ID（`AtlasDesk.tools` のキー）。画面本体は従来どおり `AtlasStudio.register(id, key, …)` で登録する。
- `order` で並び順（現在 コード=1 → デザイン=2 → 音楽=3）。最後に選んだカテゴリは `tsukuru-domain-v1` に保存され、初回は order 最小（コード）。

### カードの改行
- タイトル・説明の「・」区切りは自動で1行ずつ表示（ただし「C・M・Y・K」「RGB・CMYK」など3文字未満や英数字だけの並びは分けない）。
- 個別に指定するときは `CATEGORIES` の `lines:{キー:{title:[行1,行2], desc:[行1]}}`（文字列なら `\n` で改行）。

### カテゴリ内の切替タブ（例: コードの HTML｜CSS）
`CATEGORIES` の項目に `groups:[{id,label,keys:[...]}]` と `groupKey`（保存キー）を書くと、調べる画面に切替タブが出ます。初回は先頭のグループ、以後は最後の選択（コードは `tsukuru-code-mode-v1`）。groups が無いカテゴリは従来どおりの2列グリッド。

### 配色のコントラスト表示
`palette-contrast.js`（core.js の後に読み込み）が、配色の各色について白文字・黒文字のコントラスト比（WCAG 2.x、4.5=本文OK／3.0=大きい文字のみ）と、配色内で使える文字×背景の組み合わせを表示します。保存データの変更はありません。

### デザインの調べる画面（色コード早見表＋道具）
- 先頭に「色コード早見表」（RGB｜CMYK タブ、タップでHEX／CMYK値をコピー、選択は `tsukuru-colorref-mode-v1`）。中身は `CATEGORIES` の `quickRef`（rgb.names＝CSS色名、cmyk.values＝[名前,C,M,Y,K]）で編集。
- その下に「道具」の1列リスト（`tools:[[key,名前,説明]]`）：配色の組み合わせ／画像の色を調べる／フォント一覧／文字の読みやすさ。

### 色コード早見表のRGB値・不透明度
RGBタブの色をタップすると、HEX／rgb()／rgba()／8桁HEX を個別にコピーできるシートが開きます。rgba の不透明度はタブ上部のスライダー（0〜100%、5%刻み、`tsukuru-color-alpha-v1` に保存）で共通設定。

### コード：JSスニペットと道具（web-tools.js）
- 「HTML｜CSS｜JS」タブ（`tsukuru-code-mode-v1`、初回HTML）。JSはよく使う14件のスニペット（HTML付き・コピー・MDNリンク）。各スニペットはヘッドレスChromiumで実行テスト済み。
- 道具（`CATEGORIES` の `tools:[[key,名前,説明,ページ名]]`、ページは `TsukuruPages` に登録）：flex と grid の早見表／レスポンシブと単位変換（px⇄rem・ブレイクポイント・clamp()生成）／影と角丸の見本。
- clamp() の式：傾き=(最大px−最小px)/(最大幅−最小幅)、切片=最小px−傾き×最小幅 → `clamp(最小rem, 切片rem + 傾き×100 vw, 最大rem)`。

### コード：ワイヤーフレーム（wireframe.js／wireframe.css）
- 入口：コード → 調べる → 道具 → 「ワイヤーフレーム」。検索「ワイヤー」「wireframe」でも開けます。
- 枠：Web（PC 1440幅）／スマホ（390×844）／ゲーム横長（1280×720・16:9）。プレビューは画面幅に合わせて縮小（SVG）。
- 部品をタップすると下に積み重ねます。ゲーム枠は位置プリセット（縦：上／中／下、横：左／中央／右）で配置。
- 各ブロック：上へ／下へ／削除、高さ S／M／L、幅（Web・スマホ＝全幅／半分、ゲーム＝標準／全幅）、表示する文字（1行に1項目。ナビ・メニュー・選択肢は行ごとに項目になる）。
- 保存：`tsukuru-wireframe-v1`（`{draft, items[]}`）。名前を付けて保存／開く／削除。編集中の内容も自動で残ります。
- 書き出し：PNG（canvas に直接描画、外部ライブラリなし、現在のテーマの色）／HTMLの骨組み（header・nav・main・section・article・form・footer。Web・スマホのみ）。
- 1画面目の線：スマホ枠は 844／640／667 から選択、Web枠は 900。表示とPNGへの書き込みはそれぞれ切替可（既定オン、`tsukuru-wireframe-fold-v1` に保存）。HTML書き出しには入りません。

### ワイヤーフレームから実ページを作る（2026-11）
1. 部品を追加し、プレビューのブロックまたは一覧の名前をタップして編集。見出しはh1〜h3、文章は本文、画像は端末ファイル／URLとalt、ボタンは文字とリンク先を指定できます。
2. 「カラム」は2〜4列。「追加する子ブロック」で列ごとに文章・画像・ボタンなどを追加。「セクション」も子を持てます。列数を減らしても子は最後の列に残します。
3. 「ワイヤーフレーム表示／実表示／HTMLコード」で切替（最後に選んだ表示は端末に保存）。Web／スマホ枠でも内容は共有。実表示では600px以下でカラムと半幅を縦積みし、内容に応じて高さが伸びます。高さS/M/L、1画面目の線、PNGは設計図用です。
4. キービジュアルと画像（ゲームの立ち絵も）は、選択すると下辺のハンドルをドラッグして高さを変えられます。編集欄の「高さ（px）」でも指定でき、「自動に戻す」で S/M/L の既定値に戻します。高さは Web とスマホで別々に保存され、実表示・HTMLコード・書き出しにも反映されます（画像は指定高さで `object-fit:cover`）。未設定の枠はこれまでどおり自動高さです。
5. 「HTMLコード」では、書き出すHTMLと同じ生成器のソースを表示します。HTMLとCSSのタブ、行番号、簡易色分けがあります。長い画像データは既定で省略（`data:image/jpeg;base64,…(123KB)`）。「コードをコピー」の内容は画面の注記どおりです（省略オフなら書き出しと同じ完全なコード）。
6. 「HTMLで書き出す」でページタイトル・ファイル名を入力しダウンロード。UTF-8／日本語／viewport／埋め込みCSS／セマンティックタグ付き。プレビューと同じHTML生成器・CSSを使います。見出しは先頭h1、以降は飛び級しないよう自動補正。プレビュー内リンクは編集用、書き出し後は通常のリンクになります。
7. 端末画像はdata URIで保存・書き出し（長辺1600px以下に縮小）。URL画像もCORSが許せば埋め込みます。埋め込めないときは警告後、外部URLを残すか中止できます。完全単体・オフライン表示が必要なら端末画像を使ってください。

- 下書き・画像・alt・リンク・見出しレベル・子ブロックは端末内に自動保存。従来の `tsukuru-wireframe-v1` データも引き継ぎます。画像や名前付き保存が増えるとブラウザの保存容量（通常数MB）を超えることがあります。警告が出た変更は未保存です。画像／保存作品を減らす、またはHTMLを書き出して退避してください。端末間同期はありません。
- 対応画像：PNG／JPEG／WebP／GIF（GIFは静止画化、30MB以下）。SVG／AVIFは対象外。縮小・圧縮は非可逆です。URL画像にはCORS・通信・画像形式の制限があります。
- HTMLは静的ページです。フォームの送信、ナビの個別URL設定、任意CSS編集、サイト公開機能はありません。ボタンのリンク先は `https://…`、`mailto:…`、`tel:…`、`#…`、`./…` などを指定できます。
- 生成器：`wireframe-real.js`。既存のPNG／HTML骨組みコピー／辞典／講座は残しています。LPと会社サイトの390px／1280pxでの検証は `REALVIEW-VERIFICATION.md` を参照。

### ヘッダーのメニュー（2026-11-09）
- ヘッダーブロックを選ぶと「サイト名（ロゴの文字）」と「メニュー項目」を入力できます。メニューは1行に1つ、`ラベル | URL` でリンク先も指定（例：`作品 | #works`、`ブログ | https://…`）。URLを省くと `#`。空にするとメニューなし。
- ワイヤーフレームの右側の枠は、入力した項目の数・文字のとおりに描かれます。実表示・HTMLコード・書き出しHTMLでは `<header>` の中に `<nav aria-label="メイン"><ul>` として出力され、スマホではサイト名の下にタップしやすい大きさで並びます。
- 以前に保存したヘッダーには、これまでの見た目どおり「ホーム／作品／お問い合わせ」が入ります。独立した「ナビ」ブロックもそのまま使えます。
